Boot Doom

Enter a URL to a Doom WAD (IWAD, e.g. Freedoom). It's downloaded to RAM, run on the phone screen, and discarded on quit — nothing is stored.

Boot NES

Enter a URL to a NES ROM (.nes, iNES mapper 0–4). It's downloaded to RAM, run on the phone screen, and discarded on quit — nothing is stored.

This page is not password protected. Anyone on the network who can reach this phone can use these buttons, including making it download from a URL.
