# Game Boy / Game Boy Color emulator (Gambatte) on the snom D375

The **Boot Game Boy / Color** card in the CFW panel (and *Settings → Games →
Game Boy / Color* on the phone) downloads a `.gb`/`.gbc` ROM into RAM and runs
it with [Gambatte](https://github.com/libretro/gambatte-libretro) on the
phone's screen. It is the same frontend, launcher and CGIs as the GBA
emulator; read [gba.md](gba.md) for how those work. This page covers what is
different.

## Why Gambatte (measured, not guessed)

Two libretro GB/GBC cores were built with the same frontend and flags
(`-march=armv6 -marm`, soft-float) and run on the device with the same test
ROM (`tests/roms/sndtest.gb`, GBC mode, 20 s each, `GB_STATS=1`, 5 s windows):

| core | fps (steady) | audio underruns | CPU (top) |
|------|-------------:|----------------:|----:|
| **Gambatte** (libretro/gambatte-libretro 7809bb6) | **59.6 – 59.7** | **0** in 20 s | ~42 % |
| Gearboy (drhelius/Gearboy af215bc) | 54.3 – 54.6 (46 with a screenshot running) | ~145 per 5 s | ~82 %, while already skipping every other blit |

Gearboy is newer and has more features (SGB borders, sensors), but it cannot
keep 60 fps on a 500 MHz ARM1176 even with the frontend dropping every second
blit; Gambatte has half the load and room to spare. Gearboy stays buildable
(`CORES=gearboy tools/build-retro.sh`) for future comparisons, it is not
shipped.

## Core options (`retro-src/snom_retro.c`, `CORE_GAMBATTE`)

- `gambatte_gb_hwmode = Auto`: GBC games in colour, DMG games as DMG.
- `gambatte_gb_colorization = auto`: DMG games get Gambatte's built-in
  per-game palettes (as a GBC would), otherwise `GB - DMG` green.
- `gambatte_gbc_color_correction = disabled`, `gambatte_mix_frames = disabled`,
  `gambatte_dark_filter_level = 0`: each of those is an extra per-pixel pass.
- `gambatte_audio_resampler = cc`: cheaper than the sinc/blipper path. With
  `cc` the core delivers stereo at **65536 Hz**; `snd_hal_push_rate` box-filters
  that to 16 kHz.
- No boot ROM (`gambatte_gb_bootloader = disabled`); an optional
  `gb_bios.bin`/`gbc_bios.bin` in `/snom/cfw/gb/` is the system directory.

## Screen

160x144 is scaled by 1.889 to **302x272**, centred (89 px black borders). The
core outputs RGB565.

## Keys

Same table as GBA (nav = D-pad, Fire = A, Use = B, OK = Start, Cancel =
Select, red hangup = quit). Digits 1/3 are mapped to L/R for GBA and are
simply ignored by Gambatte. `GB_STATS=1` logs any unmapped scancode
(`gb: unmapped key N`).

## Launcher check

`lib/retro-boot.sh gb URL` accepts up to 8 MiB (the largest GB/GBC cartridge)
and requires the first four bytes of the Nintendo logo (`CE ED 66 66`) at
0x104, which every licensed and practically every homebrew ROM carries (the
real boot ROM refuses to start without it). History: `/snom/cfw-data/gb/history`.

## Building

`tools/build-retro.sh` builds Gambatte with `make -f Makefile.libretro
platform=unix HAVE_NETWORK=0` and then archives **every object** into
`libcore.a`.

Gotcha: `STATIC_LINKING=1` (the usual way to get a `.a`) leaves the
libretro-common objects (file streams, string/path helpers, VFS) out, because
a RetroArch static build provides its own copy; linking our frontend then
fails with dozens of undefined `filestream_*`/`path_*` symbols. Building the
normal shared-library object set and archiving it ourselves avoids that
(position-independent objects link fine into a static-pie binary). Gearboy
needs the same treatment.

Copy `tools/out/gambatte` to `custom-rootfs/snom/cfw/gb/gambatte`.

## Test ROM

`tests/roms/sndtest.gb` (generated by `tests/roms/mkroms.py`, hand-assembled
LR35902, CGB-compatible, no MBC): four vertical colour bars red / green /
blue / white via a CGB background palette, CH1 square arpeggio A4 C♯5 E5 A5
C♯6 A5 E5 C♯5 (one note per 16 frames, NR13/NR14 retrigger) over a constant
CH2 square at 219.9 Hz. `tests/retro.sh` checks the bars in a screenshot, the
fps, the unmapped-key log and the tones in the `SND_DUMP` PCM.

## Limitations

- Battery saves live in `/tmp` and are lost on quit (Task K persists them).
- No link cable, rumble, or Super Game Boy borders.
